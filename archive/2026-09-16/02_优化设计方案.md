# SnS/hBN/Gr 实验方案重新设计

日期：2026-09-16。对象：PPT 所示 p-SnS 横向沟道、分离 Gr 底接触、Au 引出、Si 背栅。下文中“建议”“假设”“初筛窗口”均为待验证设计，不是已取得的实验结果；尺寸、剂量和性能目标不冒充文献最优值。

## 一、决策摘要

**保留 p-SnS，暂不扩充材料种类；将接触筛查前置；把未处理 hBN 视为待验的基底隔离层，把处理 hBN 视为高风险、需证据支撑的俘获层。**

不要同时追求最大暗电导、最大响应度和最长保持。第一阶段先证明器件和测量可靠，第二阶段判断 hBN 是否带来净收益，第三阶段只对合格器件优化突触。原 G0/G1/G2 思路可保留，但增加能够排除替代机制的最少对照。

| 优先级 | 现在做什么 | 为什么先做 | 完成后才能做什么 |
|---|---|---|---|
| 1 | 校准光功率、采样链路；检查 Gr 短路及接触 | 否则所有性能比较可能失真 | 接触与界面对照 |
| 2 | 固定接触平台，比较 G0、G1、假处理 | 区分材料层、转移过程与工作点影响 | 评估 hBN 净收益 |
| 3 | hBN 见证片低剂量筛查及 G2 试验 | 防止将漏电/损伤误当记忆 | 可擦除突触测试 |
| 4 | 若有可逆保持，再优化光辅助更新 | 光可能只抬升基线，未改善存储 | 多状态与循环研究 |
| 5 | 必要时选一种替代结构 | 避免首轮全因素失控 | 空间解耦或浮栅方向 |

## 二、把三种“缺陷”分开讨论

| 来源 | 可能的作用 | 可先做的鉴别 | 不能据此直接下结论 |
|---|---|---|---|
| SnS 体内/表面及环境吸附 | 复合、载流子掺杂、慢响应 | 相与成分检查；空气/干燥惰性环境同器件复测；保护封装对照 | 一条拉曼峰不能给出陷阱密度 |
| SnS/hBN、Gr/hBN、转移残留界面 | 俘获、光栅控、接触漂移 | 假处理、Gr-only、位置选择照明、四端读出 | 迟滞不唯一对应沟道界面陷阱 |
| hBN 原生、处理及机械缺陷 | 记忆、RTS、漏电/击穿路径 | 同批介质见证结构、应力恢复、噪声/RTS；必要时化学与结构表征 | AFM 平整、无可见 PL 均不证明无电活性缺陷 |

hBN 的无悬挂键理想表面和“实际器件无电活性陷阱”是不同概念。[R06：基底收益](https://doi.org/10.1038/nnano.2010.172)、[R08：单缺陷](https://doi.org/10.1038/nnano.2015.188)、[R09：RTS](https://doi.org/10.1021/acsnano.4c06929)、[R10：隐蔽堆垛缺陷](https://doi.org/10.1021/acs.nanolett.5c06347)

对探测：希望降低工作频段内引起漂移、噪声和过慢恢复的过程。对突触：需要特定时间尺度的可逆俘获，且不能牺牲到没有可用读出信号。**不是缺陷越少或越多都好，而是要确定位置、动力学和代价。**

## 三、Gr 的重新处理方案

### 3.1 先确认它在器件中的实际角色

PPT 中 Gr 是源漏接触。先在未放 SnS 时确认两个 Gr 电极之间电阻足够大，排除连续 Gr 膜、残留带和光刻桥接。若实际结构是连续 Gr 沟道，必须单独命名，不能再称为同一套 SnS 沟道对照。

总两端电阻可写为：

`R总 = R金属/Gr,S + RGr,S + RGr/SnS,S + RSnS沟道 + RSnS/Gr,D + RGr,D + RGr/金属,D`。

任何一项在光照或栅压后变化，都可能表现为“导电性保持”。特别是 Gr/hBN 的光掺杂已有直接证据。[R07](https://doi.org/10.1038/nnano.2014.60)

### 3.2 首选处理：清洁、保护、测量，而非盲目加缺陷

1. 记录 Gr 来源（剥离/CVD）、层数、转移聚合物、残留、裂纹和电极覆盖；用 Raman D/G/2D 空间映射配合 AFM。D 峰不能单独分辨边缘与体内损伤，G/2D 位移也不能单独区分应变和掺杂。
2. 优先采用实验室已有且能复现的洁净干法转移/拾取流程，尽量不让聚合物接触关键界面。工艺收益需用电学前后对比验证，不把“干法”当作洁净保证。[R13](https://doi.org/10.1038/s41467-018-07558-3)
3. 需要去残留或退火时，先做 Gr/hBN 与 SnS 见证片的兼容性试验，再决定组装顺序。**不把石墨烯常见的高温退火条件直接施加给整套 SnS 器件**；温度、气氛和时间由相、成分、形貌及电学稳定性共同确定。
4. 不对组装好的 Gr/SnS 器件做无保护 O₂ 等离子体处理。hBN 处理必须在 SnS 和 Gr 未接触处理区域时完成，并记录处理后到组装的等待时间。
5. 先保持 Gr 掺杂状态一致。有局域静电栅时可作为可逆接触调节实验；没有时，先比较参考接触，暂不引入不稳定的化学 p 掺杂。化学掺杂只有在确证注入受限后才是候选，且须增加未掺杂、老化和光照漂移对照。

### 3.3 接触对照怎么做

首轮在同一未处理 hBN 平台比较 C-Gr 与 C-M：前者为当前 Gr 底接触，后者为**与 p-SnS 接触文献相符的 Ni/Au 或 Pd/Au 候选之一**。Ni、Pd 在特定 SnS 纳米带体系中表现优于 Ti、Cr，但不能保证在你的样品上同样成立。[R03](https://doi.org/10.1039/C7NR07403D)

尽量匹配接触几何、搭接长度和沟道尺寸。如果 C-M 是顶接触而 C-Gr 是底接触，结论只能是“接触工艺平台比较”，不能把全部差异归为功函数。必须记录实际接触 SnS 的最底层金属；有 Ti/Cr 黏附层时，不能只称 Au 接触。

优先级：低偏压双极性输出曲线与重复扫；有足够尺寸时采用四端测量；能匹配多个沟道长度时做 TLM。单个线性 I–V 不能证明接触电阻低，非欧姆样品也不能硬套线性 TLM。二维材料的干净转移接触提供方法启发，但其材料结论不能直接移植。[R14](https://doi.org/10.1038/s41586-018-0129-8)

若 C-M 的稳定性和可读性显著优于 Gr，允许后续主线采用 C-M，把 Gr 留作机制对照；不为了保持原图而保留失效接触。

## 四、探测分支 D：验证未处理 hBN 的净收益

### 4.1 基本结构与工艺

采用已筛选的同一种接触平台。D0 为 SnS/SiO₂/Si，D1 为 SnS/未处理 hBN/SiO₂/Si，Dsham 为经历同样等待、搬运、清洗/掩膜过程但不点等离子体的 D1。

首轮选 AFM 可可靠测厚、平整无明显折痕和气泡的多层 hBN。若材料库允许，可用 **10–30 nm 作为基底隔离层的试验起点**，不是最佳厚度或安全承诺；不要首轮就铺开厚度矩阵。SnS 首轮从已有成功工艺中选择一个窄厚度区间，并记录晶向，避免同时更改相、厚度和接触。对厚度较大的 p-SnS，要检查背栅是否实际能调制沟道，不能把弱栅控误判为“无陷阱”。

若环境复测提示表面吸附/氧化主导，再比较成对的顶部 hBN 保护样品。顶部封装带来的额外转移、应变与光学变化也要有对照，不与底部 hBN 效应混在首轮比较。

### 4.2 三个公平比较条件

1. 先报告相同外加 Vds、Vbg、波长、入射功率、温度和历史条件的结果。
2. 再比较可解释的匹配工作点，例如相近过驱动或相近暗电流，且明确匹配方法；**匹配暗电流不等于匹配载流子浓度，也不能单独证明接触相同**。
3. 报告有效栅电容与光学堆栈变化。平板近似下：

`Ceff/A = ε0 / (tSiO2/εr,SiO2 + thBN/εr,hBN,⊥)`。

同 Vbg 不代表同沟道电荷；hBN 不是金属屏蔽层，不能完全屏蔽底层电荷的静电作用，也不阻挡所有照向 Si 的光。薄膜干涉可能改变 SnS 吸收，因此外响应度变化不自动等于内部收集效率变化。

### 4.3 应当优化什么

先固定一个实际使用频率与光功率区间。主要看该频率下的 R、实测噪声、NEP，以及恢复到基线的时间；另报低频/准静态 R，不用它与高频噪声组合计算 D*。[R16](https://doi.org/10.1038/s41566-018-0288-z)

光电导增益模型 `g≈τ有效/τ渡越` 只作趋势解释，适用于相应输运假设。减少慢俘获可能降低 R，同时改善速度和噪声。只要目标频率的可检信号和稳定性提升，就可能是有效优化，不能因 R 单项下降就认定失败。[R15](https://doi.org/10.1021/nl502339q)、[R17](https://doi.org/10.1021/acsphotonics.5c00146)

如果 D1 电流降低：按“接触是否变差 → 栅电容/工作点 → 转移污染/材料劣化 → 慢增益减少 → 光吸收差异”逐项检查，不立即增加光功率或换更厚 SnS。

## 五、突触分支 S：先确认可逆俘获，再优化权重

### 5.1 原 G2 可以保留，但降为受控试验

结构为 SnS/处理 hBN/SiO₂/Si。必须有未处理、假处理与至少两个初筛处理级别。记录功率、压力、流量、时间、直接/远程模式、样品位置、掩膜方式及等待时间；“瓦数×秒数”不是跨设备可移植的等离子体剂量。

在同批 hBN 见证片上先看厚度/形貌、化学变化和局部漏电。使用金属/hBN/导电底电极等结构评估 hBN 本身时，应明确其电场与真实器件不同。**厚 SiO₂ 串联的完整器件 Ig 很小，也不能证明处理 hBN 局部没有损伤**。[R11](https://doi.org/10.1021/nn506645q)、[R12](https://doi.org/10.1038/s41928-024-01233-w)

不直接照搬 Fang 或 Seo 的具体处理条件。先从设备负责人认可的最低有效档位和最短可控时长开始，见证片出现穿孔、不可逆漏电跃迁或明显减薄时停止增强剂量。

### 5.2 避免处理接触区带来的混淆

优先方案是让处理区只位于未来 SnS 中央沟道下方，而未来 Gr 搭接区下方保持未处理。用与实际几何匹配的假掩膜流程控制残留。有可靠定位与低污染图形化能力才做；首轮没有能力时，保持全片处理，但加入 Gr-only 和四端/局部照明测试，并把结论限制为“器件级处理相关效应”。

如果中央处理组出现可逆记忆，而仅接触区处理组主要改变两端电阻、四端沟道变化弱，则接触贡献更值得怀疑。这个比较需要几何、处理面积和电场差异的说明，不能只比较一次峰值。

### 5.3 p 型通道的极性不能照搬

在理想静电图景下，附近负电荷可倾向于增加 p 型沟道空穴，正电荷可倾向于耗尽空穴。但真实器件还包含注入势垒、陷阱空间位置、接触栅控与可能的双极性输运，因此这只是**待证伪的方向性假设**。

先测同一初态下正、负 Vbg 脉冲；撤除脉冲后回到固定 Vbg,read 和 Vds,read；联合观察转移曲线水平位移、沟道电导及 Gr-only 的变化。界面片电荷近似下 `ΔVth≈−ΔQt/Ceff`，其中 Qt 为带符号面电荷密度。分布陷阱和接触变化时，此式不能用于精确定位或直接计算 Dit。

R09 使用 n-MoS₂ 探测 hBN 缺陷，并在讨论中提出 p 型沟道可用于探索不同能区的缺陷。这为研究 p-SnS 提供了**可思考的科学动机**，但不证明 p-SnS 更好，更不证明本课题具有首创性。[R09](https://doi.org/10.1021/acsnano.4c06929)

### 5.4 光的四组测试

每组先复位到相同初态：暗态无写入、仅电写入、仅光写入、同样电写入加光辅助。必要时加等效温升对照。每次都分别测“照光期间”和“关光后同一读出条件”的电导。

若光仅在照射期间抬高电流，关光后权重没有变化，应称光调制读出/光辅助电突触，不称光写入存储。若只有电复位有效，不称全光突触。[R01](https://doi.org/10.1063/5.0145392)、[R20](https://doi.org/10.1002/adfm.202414210)

先使用实验室可校准的一个可见波长；只有看到可靠光作用后再比较其他波长。同功率和同光子通量是两种不同控制，按研究问题分别报告。不要假定 820 nm 在 SnS 中复制 SnS₂ 的作用路径。

### 5.5 直接处理层不理想时的两条备选，只选一条

**S-spacer：空间隔离试验。** 在 SnS 和处理 hBN 表层之间插入额外的洁净超薄 hBN 间隔层，以研究通道保护与电荷交换的权衡。建议先对比“无间隔层”和一种可可靠制备的少层间隔层；它会改变隧穿和电容，也可能使写入完全消失。必须加相同间隔层/未处理底层对照。该 SnS 结构是设计假设，未由本次文献证明成功。

**S-FG：独立浮栅结构。** 用独立、完全电隔离的 Gr 作为存储节点，hBN 作为隧穿介质，SnS 仍为读出沟道；源漏 Gr 与浮栅不能电连接。底部阻挡介质、寄生电容、写入路径和保持泄漏需重新设计。MoS₂/hBN/Gr 浮栅已有依据，但 SnS 能带与注入条件必须另验。[R19](https://doi.org/10.1038/ncomms12725)

若首要目标是尽快得到可靠实验，不建议立刻转浮栅。它解决的是存储节点定义问题，同时引入更多工艺与电场设计工作。

## 六、最小对照矩阵与样本安排

| 阶段 | 组别 | 与谁比较 | 回答的问题 |
|---|---|---|---|
| A 接触筛查 | C-Gr、C-M，均在相同未处理 hBN 上 | 两者及各自重复样品 | 电流/漂移是否由接触平台主导 |
| B 探测基线 | D0=G0、D1=G1、Dsham | D1/D0、Dsham/D1 | hBN 层及工艺本身的作用 |
| C 处理初筛 | S-L、S-H，均保持其他条件一致 | 各自/Dsham | 处理强度是否带来可逆保持及代价 |
| C 见证结构 | Gr/未处理、Gr/假处理、Gr/处理 hBN | 暗/光/脉冲前后 | Gr/hBN 是否产生独立记忆背景 |
| C 介质见证 | 未处理/假处理/处理 hBN 的局部介质结构 | 漏电、应力恢复、形貌 | hBN 是否损伤，而非仅总 Ig 小 |
| D 定位确认（条件允许） | 中央沟道处理、仅接触区处理 | 相同处理条件 | 存储更靠近通道还是接触 |

采用顺序设计，不首轮全因素穷举。接触初筛每平台约 3 个独立器件；B/C 每组约 3 个独立器件只判断可行性。进入主结论的关键组建议扩展至每组至少 5 个独立器件、覆盖至少 2 个制备批次，最终样本量按初筛变异与希望识别的效应决定。这些数量是资源规划，不是统计充分性证明。

同片多个循环是重复测量，不能当多个独立器件。尽量做同母晶/同厚度/同晶向配对，同时跨批复现；随机化测试顺序，记录每个制造样品及失败原因。接触平台变更后必须重建对应基线，不能把不同平台的数据混为 G0/G1/G2。

## 七、继续、调整与停止的依据

| 观察到的结果 | 暂时解释 | 下一步决策 |
|---|---|---|
| Gr-only 已出现相似保持/光漂移 | 接触背景不能忽略 | 先改善/隔离接触，不扩大“SnS 突触”主张 |
| D1 的 R 降低，但恢复更快、目标频率 NEP 更低 | 可能减少慢增益并改善有效探测 | 保留探测分支，报告权衡 |
| D1 在配对重复中无净收益 | hBN 无优势或其他过程主导 | 排查环境/接触；不预设 hBN 必需 |
| G2 保持增强但电导可读性变差、噪声和漏电升高 | 可能以损伤换保持 | 降剂量；若两轮独立初筛仍不可逆，暂停直接处理路线 |
| G2 在固定读出点下有可擦保持，Gr-only 弱、沟道四端变化明确 | 支持通道相关存储，但未唯一定位原子缺陷 | 做温度/应力/空间对照后再谈机制 |
| 光下循环规整，但关光后状态消失 | 光导偏置而非持久光写入 | 归为光辅助操作，勿报光存储 |
| 连续读出使保持迅速衰减，间歇读出稳定 | 读扰动重要 | 降低读偏压/占空比，分开报告 |

建议先预注册最小可检变化、允许漂移和失败排除规则，见 `03_测试SOP与判据.md`。不要通过挑选最佳器件、删除不规则周期或只展示归一化曲线来达标。

## 八、可以成立的成果边界
