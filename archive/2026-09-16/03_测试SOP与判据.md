# 测试 SOP、指标口径与失败排查

适用范围：p-SnS 横向器件的初筛与机制比较。所有建议门槛均为**本项目初筛规则示例**，不是行业标准、文献纪录或已达到的指标。必须先按仪器分辨率、器件安全范围和目标应用冻结实际规则。

## 1. 每个样品必须具备的记录

| 类别 | 最少记录项 |
|---|---|
| 身份 | 器件编号、批次、母晶/材料来源、SnS 相与厚度、hBN 来源与厚度、Gr 层数与形态 |
| 几何 | L、W、晶向/偏振关系、接触搭接、通道/接触照片、hBN 覆盖及处理范围 |
| 工艺 | 转移顺序、聚合物和清洗、退火气氛/温度/时间、等离子体完整条件、处理后等待时间、空气暴露 |
| 电学 | 接线图、实际底层金属、Vds/Vbg 极性、扫速/方向/驻留、读偏压、预处理、漏电和限流 |
| 光学 | 波长、样品面功率或功率密度、光斑及空间分布、入射角、偏振、有效照明面积、调制方式 |
| 仪器 | 型号、量程、积分时间/NPLC、采样率、滤波、放大器增益及带宽、同步时序和校准日期 |
| 环境 | 温度、湿度或气体/真空条件、暗适应时长、测量日期及顺序 |
| 数据 | 原始带符号电流、时间戳、光/栅触发记录、处理脚本版本、失败标记与原因 |

原始文件只读保存。分析结果与原始记录分开。保留全部制造样品清单，不能只记录工作良好的器件。

## 2. 先检查测量，再评判材料

### 2.1 电学检查

1. 空载、短路或已知电阻验证测量系统的偏置、噪声与瞬态响应；检查探针、接地和屏蔽。
2. 未放 SnS 的源漏 Gr 结构检查有无桥接。Gr 连续跨沟道时，重新定义结构或重新制样。
3. 低 Vds 起步，先检查电流限幅与稳定性，再逐步拓展安全范围。记录有符号 I–V，不只保存对数绝对值。
4. 同时记录 Id、Ig；阶跃后的位移电流与稳态漏电分开。量程切换、积分时间或触发尖峰不计入光电流/PSC 峰值。
5. 转移曲线至少固定三种可分辨扫速并测双向扫描，使用同样的起点、终点和初态；先小窗口，后在见证结构验证下扩展。

### 2.2 光学检查

用功率计在**样品面、实际光路和同样物镜/窗口后**校准，不把激光器面板功率当器件入射功率。若光斑大于沟道且近似均匀，`Pinc=p面×A有效`；若光斑小于器件或呈高斯分布，按实际光斑与有效区域交叠积分。记录金属遮挡，不能按器件总外形面积机械计算。

先用一个已校准可见波长做对照；通过后再加光谱和偏振。固定光功率时注意热漂移，必要时监测样品温度。先做器件中心、两侧接触、邻近裸基底位置的照明测试；大光斑无法空间分辨时如实注明，不把遮挡实验当成完美定位。

Si 基底及 Gr 也可能参与光响应，需要基底/接触背景。局域金属栅或遮光设计可作为后续对照，但改变电容、热及光学边界时必须重新匹配，不能当作无副作用的“屏蔽”。[R07](https://doi.org/10.1038/nnano.2014.60)、[R17](https://doi.org/10.1021/acsphotonics.5c00146)

## 3. 电导与接触：解决“导电性差”的入口

- 低偏压近线性区域报告 `G=I/Vds`，更严谨可取 `dI/dVds`。非线性器件只能报告指定读出点的工作电导，不称本征电导率。
- 若有可靠几何且接触电阻已排除，矩形均匀通道可用 `σ=G×L/(W×t)`；薄片也可报片电导 `G□=G×L/W`。有接触影响时注明表观值。
- 线性低偏压 FET 近似下：`μFE=L/(W Ceff Vds)×dId/dVbg`。Ceff 是单位面积栅电容。严重迟滞、非欧姆注入、接触随栅变化或屏蔽明显时，不将其称为本征迁移率。
- TLM 使用 `Rtot=2Rc+R□L/W` 的前提是近欧姆接触、几何一致、载流子密度相近。至少多个长度，报告拟合和误差；四端探针须位于有代表性的均匀沟道区域。

先回答：是 Rcontact 太大、通道载流子太少、通道受损，还是实际读出点接近关断？调大 Vds 可能同时提高暗电流、热效应及噪声，不是通用修复。

## 4. 探测测试流程

### 4.1 推荐顺序

暗态稳定与漏电 → 小范围输出/转移 → 一个波长的光功率扫描 → 开关光和恢复 → 调制频率响应 → 匹配频率噪声 → 环境/重复性 → 有证据后再拓展光谱。

首轮探索可在安全条件下考察多个低读偏压，例如 10–100 mV 档位；此范围不是对所有样品适用的固定配方。栅压幅度必须根据实际介质厚度、场分布、限流及应力稳定性决定，不能从 PPT 的 ±70 V 文献图照抄。

光功率建议覆盖至少一个可校准且未饱和的数量级并取多个点，按对数分布方便分析。先确定稳态是否存在，再报告稳态 R；若有持续漂移，改报明确照射时间下的瞬态 R 和基线定义。

### 4.2 统一指标

| 指标 | 定义与单位 | 容易出错的地方 |
|---|---|---|
| 光电流 | `Iph=Ilight−Idark`，A | 必须在相同偏置/历史和明确时间窗下；保留正负号 |
| 响应度 | `R=Iph/Pinc`，A/W；灵敏度计算常用其幅值 | 功率是落在有效区域上的功率，不是光源总功率 |
| 外量子效率 | `EQE=R hc/(qλ)`；百分数为 `R×1240/λ[nm]×100%` | 增益器件可超过 100%；负光响应时应说明符号，不能简单解释为负量子产额 |
| 电流噪声 PSD | `SI(f)`，A²/Hz | 不等于其幅度谱密度，也不等于积分噪声 |
| 噪声幅度谱密度 | `in(f)=sqrt(SI(f))`，A/√Hz | 报告频率、偏置、量程及背景 |
| 频率相关 NEP | `NEP(f)=sqrt(SI(f))/abs(R(f))`，W/√Hz | R 和噪声必须匹配频率和工作条件 |
| 比探测率 | `D*(f)=abs(R(f)) sqrt(A)/sqrt(SI(f))` | A 用 cm² 时单位 Jones；微器件的面积缩放并不总理想 |
| 积分噪声 | `irms²=∫ SI(f)df`，A² | 实际还应包含测量滤波传递函数；不能随意取白噪声近似 |
| 散粒噪声估计 | `sqrt(2q abs(Idark))`，A/√Hz | 只有证明其主导才可作为 D* 分母；低频 1/f、RTS 等可能更重要 |

无法可靠测噪声时，先报告 R、瞬态、漂移和噪声上界/仪器分辨率；D* 若只由散粒噪声估计，明确标成“模型估计，非实测”，不要与文献实测 D* 排榜。[R16](https://doi.org/10.1038/s41566-018-0288-z)

不要把仪器背景曲线不加判断地做平方相减。只有独立、非相关、同频带且差异可分辨时才有意义；接近噪声底时报告限制，而非产生虚假的超低噪声。

### 4.3 速度、拖尾与功率依赖

1. 明确 10%–90% 上升、90%–10% 下降的基线和稳态；采样点应足够密，光调制边沿/放大器带宽应优于被测动态。
2. 若仪器限制速度，只报告仪器受限结果，不能声称器件达到更快时间。
3. 同时报主响应和慢尾：定义 `Ttail(t*)=abs(I(t*)−Ipre)/abs(Ion−Ipre)`。t* 为关光后的指定时刻，所有组一致，分母必须明显高于噪声。
4. 对长期不恢复的样品，报告截止时间内的残余值，不能将任意截断拟合成完整寿命。
5. `Iph∝P^α` 的 α<1 可提示陷阱/饱和等非线性，但不能唯一识别机制；与栅压、温度、空间照明和背景对照联合判断。
6. 多指数/拉伸指数拟合是动力学描述，不等于发现了对应数量或原子身份的陷阱。[R15](https://doi.org/10.1021/nl502339q)

### 4.4 噪声与 hBN 陷阱排查

稳定工作点采 I(t)，检查趋势、功率谱和是否有离散 RTS。测多个栅压，设备允许时再加温度扫描；报告每个温度的稳定时间与可观测时间窗。RTS 的捕获/发射时间可能随栅压和温度变化，器件中没有看到 RTS 也不能证明没有陷阱。[R09](https://doi.org/10.1021/acsnano.4c06929)

若采用 `SI/gm²` 比较等效栅压噪声，需先说明通道载流子数涨落假设，避免 gm 接近零或接触主导时产生失真。不能直接从一条 1/f 曲线可靠反推出精确 Dit。

## 5. 突触测试流程

### 5.1 读写分离是前提

每个周期固定：初态复位 → 等待稳定 → 写脉冲 → 撤除写入与光刺激 → 等待仪器稳定 → 固定 Vbg,read、Vds,read 读取 → 保持 → 擦除 → 再读。

先在安全幅度内试正负极性；脉宽可以按仪器能力选 1、10、100 ms、1 s 等对数档作探索，不必一次全测，不能在仪器分辨不了的脉宽下报告更新。选到能分辨而不饱和的单脉冲后，再考察数量/间隔。

既记录脉冲边沿电流，也记录稳定读出电导，但**不把边沿位移尖峰当突触权重**。读写波形的实际到达时间用触发通道或监测端验证。

### 5.2 保持、复位与可塑性

| 项目 | 记录方式 |
|---|---|
| 初态 | 写前 `Gpre`，同时记录基线噪声和漂移 |
| 写入强度 | `ΔGwrite=G(t0)−Gpre`；t0 为写后稳定且固定的第一个读时刻 |
| 归一化保持 | `F(t)=[G(t)−Gpre]/[G(t0)−Gpre]`，分母太小时不计算 |
| 状态漂移 | 同时报绝对 G(t) 和相对初态变化，不只归一化 |
| 擦除误差 | `abs(Gerase−Gpre)/abs(Gmax−Gmin)`，动态范围定义固定 |
| 读扰动 | 连续读与间歇短脉冲读对照；必要时读出后断偏压保存再重接 |
| STP/LTP | 按预先规定的时间窗和保留量描述；不把一次秒级拖尾等同长期非易失存储 |
| PPF | 可用 `(A2−A1)/A1×100%`，或 `A2/A1×100%`，必须说明；A2 的基线扣除方式一致 |
| LTP/LTD | 同样初态、固定读取延迟，记录每一步 G，而不是脉冲过程最大电流 |
| 状态数 | 由独立重复的噪声/漂移及相邻状态间隔判断，不等于施加脉冲数 |

建议先测至 10、100、1000 s，设备和样品稳定后再延长。它们是观察时间点，不是“达到即成功”的行业门槛。宣称非易失保持需在撤除写入/读出偏置的条件下验证，不能把持续偏置测量外推到数月或数年。

LTP/LTD 首轮可试每方向 20–50 个相同脉冲，避免一开始饱和；再做多轮完整增强/抑制循环。若改用自适应或逐渐增强的写脉冲，需标为“脉冲策略优化”，并保留固定脉冲的器件本征比较，不能混淆。

### 5.3 更新质量与能耗

- 同时给绝对 G 和统一端点归一化曲线。不要每个周期各自缩放后掩盖漂移。
- 为减少不同论文非线性拟合定义的混淆，可补充自定义透明指标：归一化曲线对端点直线的均方根偏差、正反程反转对齐后的平均差、循环端点漂移。给出公式和采样方式；这些是项目指标，不能直接当论文的 A 或 β 参数。
- 可分辨状态示例规则：相邻均值差大于合并读噪声的 3 倍，并超过所选保持窗的漂移；这是初筛规则，正式工作需评估错误率，不是普适“3σ 状态标准”。
- 电能按各端口 `∫V(t)I(t)dt` 记录，并明确回收能量/驱动电路是否计入；光能为 `∫Pinc(t)dt`。栅电容充放电能不能因 Ig 很小而忽略。只有电写入加光辅助时，报告两部分，不能仅用 `Vds×峰值电流×脉宽` 宣称总写入能耗。[R18](https://doi.org/10.1038/s41467-018-07572-5)、[R19](https://doi.org/10.1038/ncomms12725)

## 6. 初筛门槛示例与放行规则

| 门槛 | 可预先采用的初筛例子 | 不满足时 |
|---|---|---|
| 信号可分辨 | 在规定带宽内，光/写入变化量 ≥5 倍基线 rms 波动 | 提高校准和测量可信度，报告检测上限，不算高性能 |
| 基线稳定 | 无刺激同长度记录中的漂移小于待测变化量的 10% | 先排查环境、接触和预处理 |
| 漏电背景 | 已验证的稳态漏电/串扰低于目标电流变化的 1%，或证明其耦合可忽略 | 不能从小于量程的读数推定达标；测得不出则保留不确定性 |
| 复位 | 复位误差小于动态范围 5%，多轮和独立器件均可复现 | 不进入大量多状态测试 |
| 循环稳定 | 初筛 20 轮内端点漂移小于动态范围 10% | 排查饱和、读扰动和不可逆变化 |
| 统计复现 | 报全部独立器件点、组中位数与离散性，关键结论跨批 | 不用最好的一台代表总体 |

上述百分数是讨论起点，可按实际任务调整，但应在看完最终结果前固定。不能把“初筛通过”写成已达到成熟探测/存储器件标准。

## 7. 针对目前“数据不好看”的最短排查表

| 症状 | 先测什么 | 再考虑什么 |
|---|---|---|
| 暗电流和光电流都小 | 接触连续性、低压 I–V、Gr/SnS 搭接、实际栅控 | 薄片损伤、通道电阻与吸收，不能只加光 |
| 暗电流大、光暗比低 | Gr 桥接、读出工作点、寄生光照与偏压发热 | 接触/异质结方案；总电流大不代表好 |
| R 很大但下降很慢 | 同频 R/噪声、长时关光恢复、功率/扫速依赖 | 慢陷阱增益而非高带宽探测 |
| 加 hBN 后 R 变小 | 接触/电容/吸收差异，再看 NEP 与速度 | 若慢增益减少且有效探测改善，可保留 |
| 处理后保持变长但越来越不可擦 | Ig、见证片局部漏电、低频噪声、连续/间歇读 | 损伤/注入不可逆；降剂量或停止 |
| 光照后曲线规整，撤光后不保持 | 相同暗态读出点的电导、光-only 对照 | 光调制读出，不是光存储 |
| 各样品差异特别大 | 厚度、晶向、接触、残留、转移时间与批次 | 不急做更多处理剂量，先提高一致性 |

## 8. 最小原始数据字段模板

```text
device_id,batch_id,group,run_id,time_s,Vds_V,Vbg_V,Id_A,Ig_A,
light_on,wavelength_nm,Pinc_W,power_density_W_cm2,temperature_K,
sample_rate_Hz,current_range_A,integration_time_s,read_delay_s,
pulse_number,pulse_width_s,pulse_amplitude_V,reset_method,notes
```

这些是字段模板，不是虚构数据。所有时间序列保留真实时间戳；功率密度和 Pinc 不能无说明地互相替代。
