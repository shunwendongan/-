## 近期行动

1. 确认印章为GelFilm、裸PDMS、PPC/PDMS或PC/PDMS；核对薄片横向尺寸能否覆盖沟道与接触搭接。
2. 分别记录拾取、释放、对准/完整、界面、电学五阶段结果，每批只改变一个主要因素。
3. 核对仪器源模式、单位、合规限值和接线，用已知电阻验证测量链。
4. 对器件固定执行“暗态I–V → 暗态稳定性 → 单波长开关光 → 暗态I–V复测”。
5. 得到可复测基线后开展G0/G1对照；有可逆写擦证据后再扩展G2的保持、多级状态与循环。

## 本次材料中的关键判断

- 照片中约2–4 μm的标注是横向尺寸，不能据此判定厚度、晶相或单层。
- 一张仪器截图存在Vd变量名、μA扫描单位及NaN步数的配置疑点，需核对实际源模式；照片不足以认定实际测量出错。
- PPT展示的性能曲线注明文献来源，不是学生器件的实测结果。
- SnS₂/处理hBN文献不能直接证明p-SnS具有同样的写入极性、能带和处理窗口。
- 探测率公式中的Δf为带宽；用户提供的中译文将其解释为积分时间，此处需纠正。
- 高速响应、噪声与绝对响应度需要相应带宽和光功率校准，不能仅凭探针台界面确认能力。
