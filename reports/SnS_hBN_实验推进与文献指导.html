先把转移失败拆成五类

首先明确实际印章是 GelFilm、裸 PDMS、PPC/PDMS 还是 PC/PDMS。它们依赖的黏附与释放机制不同，不能把不同论文的温度、速度和溶剂拼成一套工艺。若 SnS 已直接剥离在印章上，“拾取”记为不适用，不人为计入良率。

失败现象先检查下一批只改一项
片留在供体上供体/印章是否真实接触；表面状态、印章老化、实际聚合物按当前材料体系的既有可用窗口调整接触或拾取过程
片一直粘在印章释放机制、受体洁净度、是否有电极台阶黏弹性印章先比较可记录的两档慢释放速度；热释放体系按其已验证温度窗口试验
落下但错位、裂片或卷起台面倾斜、热漂移、接触后横向移动、过压回弹先在同温度空白标记基底校准漂移；接触后不横向拖动
气泡/褶皱跨过沟道接触前沿、颗粒、过压、界面暴露保持材料/温度不变，比较接触前沿推进方式；不先靠高温补救
看似完整但电学不通源漏搭接、台阶悬空、裂纹、Gr连续旁路、接触污染先查几何与落针，再测接触；不立刻归因于hBN缺陷

微米薄片的几何预检：沿计划电流方向，薄片可用长度应覆盖沟道 L、两端实际搭接 l₁/l₂ 和对准余量 2δ，即 ℓ可用 ≥ L+l₁+l₂+2δ。这里是设计约束，不是测得的尺寸。若实测几何不满足，继续练手也不会得到完整器件；应选更大片或匹配电极间距。优先选形貌完整、厚度可测的薄片建立流程，暂不以最薄为目标。

下一批的具体做法：先用同类牺牲片在平坦见证基底练释放，再转移到真实电极台阶。每次保存接触前、初接触、前沿通过、抬离后四张图，记录印章批次、台面实温、停留时间、释放速度或“相同距离所用秒数”、空气暴露与失败类型。光学合格候选再排 AFM/Raman；不要给每个失败片安排全套表征。

第一轮可做基线与一个变体各5次、交替顺序，作为定位问题的小样本筛选，不称统计最优。第二轮在另一天复核较好的条件，保留每次失败。10次是建议工作量，可随材料库存调整。记录 N尝试 → N释放 → N几何合格 → N界面合格 → N电学合格，分母和损失原因都保留。

上述方向来自黏弹性转移、热拾取和界面清洁原始研究 [1–3]。在明确印章/聚合物及SnS兼容性前，本报告不指定统一烘烤、等离子体或溶剂配方。

照片6中“Vd”与μA扫描值、NaN步数不一致，优先核对；照片2可能是正常的电流源扫描，仅凭变量名不能判断。EasyEXPERT 中真正决定输出的是通道源模式；电压源设电流限值，电流源设电压限值。先保存实际设置与接线图，再建立学生自己的固定模板 [10]。

顺序操作与保存内容通过后再做什么
1 系统空白断开器件测开放状态漏电；用已知电阻检查I–V斜率、极性、单位与限流状态电阻值应在其公差与仪器不确定度范围内；异常先查线缆/接地/配置
2 落针与几何探针落在引出焊盘；拍照，确认源/漏/背栅，确认背栅真实导通在已验证低应力窗口扫输出；前期可从数十mV量级试探，仍须结合器件与合规限值
3 暗态基线固定量程/积分设置，保存真实时间戳；暗I–V正反扫、暗I–t、复落针重测看跳变、漂移、合规标志；近零电流不直接等于低暗流器件，也可能开路
4 栅控与漏电仅在介质厚度和安全窗口已知后扫Vbg，同步记Ig；保留扫描方向、速度和等待Ig变化足以解释Id变化时暂缓机制解释；同扫速比较迟滞
5 单波长光开关样品面校准功率与光斑，固定Vds/Vbg；暗→光→暗多周期，再测暗I–V先得到可复测Iph、恢复和漂移，再扩到功率、频率及波长

建议首轮门槛：同一器件重复3次、至少一次重新落针；初始可将信号明显超过基线波动（例如≥5σ）且漂移小于拟比较效应作为筛选规则。σ须来自同带宽、稳定的暗态片段；慢漂移要单独报告，不能靠去趋势制造显著性。这些是预实验约定，不是领域统一标准。独立器件与同一器件重复不能混作样本量。

如果数据仍差：复落针后突变先查针/焊盘；持续开路查搭接与断裂；不随栅调且电流很大查Gr或金属桥连；整流先考虑接触势垒；光响应与显微照明联动就关闭背景灯并复测；光响应慢先核查积分时间、自动量程和光源开关，再解释陷阱。两端线性I–V不足以单独证明低接触电阻，资源允许时再做四端/TLM。

照片没有证明现有设备具备高速瞬态、锁相、低噪声前放和功率计。当前可先完成低速筛查；若未校准样品面功率，只报告Iph和相对稳定性，暂不报告绝对R；若测量带宽不足，不把采样间隔称作器件响应时间。

对照逐级加入，避免一次做满所有组合

阶段最小比较回答的问题 / 推进条件
A：工艺平台固定接触方式，先做最简单G0；平坦/带台阶见证转移找到主要良率损失；获得可重复输出与光开关
B：hBN净收益G0与G1，匹配SnS厚度、沟道、接触、暴露和测量历史hBN是否改善恢复/漂移；不要只比较峰值电流
C：处理作用G1、假处理G1、低剂量G2；hBN组装前处理假处理保持搬运、腔体停留/热历史相近但不开等离子体；先看损伤/漏电再看保持
D：机制补充Gr/hBN背景；必要时接触区/沟道局部照明或一种参考接触排除Gr光掺杂与注入变化；小光斑不足以分离区域时明确分辨率限制

初步比较每组争取至少3个独立器件并报告全部结果；作为可行性筛选，不足以宣布普适性能。后续按离散程度扩样并跨制备日复核。接触策略改变时，为新策略重新建立基线，不能将不同接触的G0/G1直接作界面因果比较。

hBN插入还改变栅电容与几何。同栅压下的电流差可能不全来自陷阱；记录介质厚度，按串联介质估算电容并注明近似，必要时比较可比载流子状态。G1底部hBN也不等于SnS顶面封装，空气暴露仍需单独控制。

图最少数据可以形成的结论

原始数据处理顺序：只读保存原始导出 → 单位统一为V/A/s/W → 保留量程和合规状态 → 按真实光开关时间分段 → 用预先约定窗口求暗/亮均值与波动 → 每周期计算Iph及恢复 → 画每个独立器件的结果 → 再做组间汇总。开关瞬态、合规点、异常点要标记，不无痕删除。自动量程或不均匀时间采样的数据不能直接当均匀采样做FFT。

Iph = Ilight − Idark
R = Iph / P有效，单位 A/W
EQE = R·hc/(qλ)；百分数再乘100%
NEP(f) = √Sᵢ(f) / |R(f)|，单位 W/√Hz
D*(f) = √A / NEP(f)，A以cm²计，单位Jones

P有效是落在约定有效区域的光功率；均匀光斑可用功率密度×照明重叠面积，非均匀聚焦光斑需空间积分/校准。不能使用激光器面板功率直接替代，也不能把整个薄片面积自动当有效沟道面积。Sᵢ是电流噪声功率谱密度，单位A²/Hz；若测的是指定带宽内RMS噪声，白噪声近似下D*=R√(AΔf)/i_rms，需交代带宽及响应匹配。

现有中译材料需纠正：Sheng论文中译将Δf解释为“积分时间”，此处应为带宽。R和噪声必须在相容偏置、频率条件下比较。仅由暗电流算√(2qIdark)所得D*属于散粒噪声模型估计，不能称实测。低频1/f噪声显著时尤其不能替代噪声测量 [8]。

上升/下降时间使用10–90%/90–10%规则，记录光源边沿、采样、放大器与滤波带宽；慢尾另报，例如固定撤光延迟的残余信号比例。没有稳定平台或仪器跟不上时，报告当前条件下的表观响应并说明测量限制。Iph∝Pᵅ的拟合只能提供机制线索，不能独自证明陷阱位置。

突触后续：先写入→撤刺激→固定读出→擦除→再次读出，正负脉冲均做且限制在已验证电场窗口。先证明少量循环可逆，再增加循环数、保持时长、多级状态和LTP/LTD；每级分布必须可分辨，并检查读扰动。光照时电流变化不等于撤光后存储。不要在可擦除还未成立前投入图像识别仿真。

按阶段验收推进两周，随后只扩有效分支

建议时间当期任务必须交付 / 不通过如何处理
第1–2天确认印章与电极几何；核对仪器源模式；整理现有器件一张制样流程、接线图、失效分类；系统电阻验证未过则先修测量链
第3–5天基线/单变体转移；平坦受体到真实台阶四时刻照片和逐级良率；释放过了而导通差，就转向搭接/接触
第6–7天固定工艺做G0，暗态与一个波长光开关可复测器件和原始曲线；未通则继续A阶段，不强行启动处理hBN
第2周前半对比G0/G1；统一厚度、环境和测量模板跨器件恢复/漂移/响应比较；结论允许为hBN无净收益
第2周后半，条件具备时假处理与低剂量hBN见证，再探索G2写擦形貌、漏电与可逆状态；不可逆损伤则收窄处理窗口或保留探测主线
第3–6周复核有效分支，补频响/噪声或保持/循环跨批次数据与机制对照；两条分支不要求同时铺开

时间是排程建议，制样与预约周期长时顺延。每天结束只填三项：今天淘汰了哪个解释、哪组数据可以复测、下一次只改哪个变量。将制样、等待表征和数据整理穿插安排；每次测量当天出基本图，不等一周后才发现单位或接线错误。

加快进度的资源顺序：先使用现有显微/转移/探针条件，并确认可借用的功率计；对有希望的样品预约AFM/Raman；只有稳定器件才预约高速瞬态、噪声、温变或化学表征。没有这些设备的近期可完成目标，是可复测制样和经校准的低速光电对照。

开题答辩应承诺可检验的问题

原PPT已经把快速探测与记忆分成两条支线，这一点合理。当前最需要调整第9页：第一阶段不同时铺开G0/G1/G2和处理梯度，改为“制样良率与电学基线 → G0/G1 → 条件成立后G2”。第4页补实际层厚与接触搭接，第5–7页持续标注“文献结果 / 拟开展”，第8页补因果对照与测量带宽。

本课题先建立可重复的p-SnS制样与测量平台，再检验未处理hBN是否改善响应恢复和稳定性。在此基础上研究处理hBN能否形成可写、可擦的电导保持，并区分界面、接触与光照历史的贡献。

可以把工艺窗口、良率变化、失败原因与可复测对照作为阶段进展。不能将“堆出了结构”写成性能验证，不能仅凭迟滞写成非易失突触，也不能把SnS₂结论改个材料名字用于p-SnS。

Sheng论文第6b/6d确实对应α-SnS，原PPT这两项标注可以保留；但题目中的air-stable和摘要的最佳暗电流/速度主要对应β-SnS，不是机械剥离α-SnS的性能保证。该文α-SnS样品的老化结果提示应记录暴露历史，不能据此断言学生所有薄片已氧化失效。
